📌 基础篇
语C / 语擦 ›
语言Cosplay的简称，即用文字进行角色扮演。参与者以特定角色身份写作对话和动作，与其他玩家互动的网络文字扮演游戏。
皮 ›
皮就是你要饰演的角色，可以是一个人，也可以是动物、玩偶等等。
皮上 / 皮下 ›
皮上 = 角色状态，以角色身份说话做事。皮下 = 现实中的自己。类似演员与角色的区别。
对皮 ›
固定的角色扮演搭档。两个人各扮演一个角色，互相配对演绎故事。
1 / 0 / 0.5 ›
源自同性关系中的角色定位。1 = 攻方，0 = 受方，0.5 = 可攻可受。常用于征皮帖中表明倾向。
BLC ›

📌 社交篇
代发 ›
代替别人发征皮/扩列/宣传帖
皮下女 / 皮下男 ›
标注扮演者的现实性别。
名人朋友圈 ›
语c圈常用的角色扮演社交平台，简称"名朋"，圈内常以"黑白"代称。每个人可在软件中有多个"皮"，每个皮有唯一编号，如"路人甲1828739"。
走 彩色 / 黑白 ›
彩色：QQ 的代称，即通过QQ联系；黑白：名人朋友圈的代称，即通过名人朋友圈联系；双通：两个都可以
卡×× ›
特殊条件限制，如"卡18+"要求扮演者年满18岁。
